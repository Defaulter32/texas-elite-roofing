# Texas Elite Roofing & Construction

A modern, high-performance web experience for **Texas Elite Roofing** — specializing in premium roof repair, replacement, inspections, and home restoration across North Texas.

---

## 🚀 Live Demo & Repository

- **GitHub Repository**: [Defaulter32/texas-elite-roofing](https://github.com/Defaulter32/texas-elite-roofing)
- **Local Dev Server**: `http://localhost:5173/`

---

## ✨ Features

- **Smooth Animated UI**: Powered by Framer Motion, featuring smooth scroll reveal, film grain overlay, and cinematic preloader animations.
- **Interactive Navigation**: Floating Pill navigation bar with theme detection and smooth section scrolling.
- **Service Showcases**: Dedicated sections for Roof Inspections, Full Roof Replacement, and Emergency Repairs.
- **Featured Projects**: Interactive carousel exhibiting modern residential and commercial roofing projects.
- **Customer Testimonials**: Interactive review slider featuring genuine homeowner feedback.
- **Contact & Quote**: Direct quote inquiry form with instant action CTA.
- **Responsive & Accessible**: Fully mobile-responsive layout built with semantic HTML and accessible navigation markers.

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`, `pnpm`, or `yarn`

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Defaulter32/texas-elite-roofing.git
   cd texas-elite-roofing
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview production build**:
   ```bash
   npm run preview
   ```
